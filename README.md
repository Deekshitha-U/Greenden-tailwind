# Greenden – Tailwind CSS Website

Greenden is a responsive plant-themed website built using HTML and Tailwind CSS. The project focuses on creating a clean, modern, and responsive user interface using Tailwind CSS utility classes without writing custom CSS.

## Features

* Responsive navigation bar
* Mobile-friendly design with hamburger menu
* Plant and product sections
* Product cards and categories
* Clean and modern user interface
* Responsive layouts using Tailwind CSS breakpoints
* Hover effects and interactive elements
* Compatible with mobile, tablet, and desktop screens

## Technologies Used

* HTML5
* Tailwind CSS

## Project Objective

The objective of this project was to practice Tailwind CSS and responsive web design by building a complete website using utility classes instead of traditional CSS.

## What I Learned

* Tailwind CSS utility classes
* Flexbox and responsive layouts
* Responsive breakpoints
* Spacing, sizing, and typography
* Hover and interactive states
* Responsive navigation menus
* Creating reusable website sections using Tailwind CSS
* Connect products to a backend
* Add animations and interactive features
